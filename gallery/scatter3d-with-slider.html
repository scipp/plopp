Scatter3d plot with slider#

In this example, we combine a three-dimensional scatter plot with a slider, which is used to navigate the time dimension of our data.

[1]:

import plopp as pp
import scipp as sc
import numpy as np

Generate data on a curved panel#

We first generate some data that represents events detected on a cylindrical detector panel, as a function of time.

[2]:

nphi = 100
nz = 20
nt = 50

r = sc.scalar(10.0, unit='m')
phi = sc.linspace('phi', 0, np.pi, nphi, unit='rad')
z = sc.linspace('z', -3.0, 3.0, nz, unit='m')
t = sc.linspace('time', 0.0, 6.0, 50, unit='s')

x = r * sc.cos(phi)
y = r * sc.sin(phi)

h, _ = np.histogramdd(np.random.standard_normal(size=[10_000, 3]), bins=(nt, nz, nphi))
a = sc.array(dims=['time', 'z', 'phi'], values=h, unit='counts')
sizes = a.sizes.copy()
del sizes['time']

da = sc.DataArray(
    data=a.flatten(dims=['z', 'phi'], to='pixel'),
    coords={
        'x': sc.broadcast(x, sizes=sizes).flatten(to='pixel'),
        'y': sc.broadcast(z, sizes=sizes).flatten(to='pixel'),
        'z': sc.broadcast(y, sizes=sizes).flatten(to='pixel'),
        'time': t,
    },
)
da

Use Plopp’s in-built dimension slicer#

To construct our interface with a slider that would output time slices of the data, we leverage Plopp’s in-built DimensionSlicer class.

It accepts a DataArray as input, creates sliders for the dimensions to be sliced (controlled via the keep argument), and makes the sliced data available in its output.

[3]:

from plopp import DimensionSlicer

# DimensionSlicer object: keep the pixel dim, slice the other (time) dim
sl = DimensionSlicer(da, keep='pixel')

# We pass the output of the slicer (which is a Node) to the scatter3d figure
fig = pp.scatter3dfigure(sl.output, size=0.3, cbar=True, autoscale=False)

# Add the slider below the figure for display
fig.bottom_bar.add(sl.slider)

fig

[3]:

Range or single slice#

By default, the Slicer will create a combined slider that allows to switch between selecting a range or a single slice.

The mode can be chosen at creation; the possible choices are combined, single, range:

[4]:

sl = DimensionSlicer(da, keep='pixel', mode='single')
fig = pp.scatter3dfigure(sl.output, size=0.3, cbar=True, autoscale=False)
fig.bottom_bar.add(sl.slider)

fig
